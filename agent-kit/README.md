# Experimental runtime agent-kit

For the plain-file personal-record workflow, use the
[Helseark skill](../skills/helseark/SKILL.md).

This directory contains the separate CLI's versioned instructions for runtime
vaults and packets. Its `START-HERE.md` applies to those archives, not to a new
folder created with the skill. See the [optional CLI overview](../docs/optional-cli.md)
for current capability guidance.

Manifest-listed files and retained copies are hash-pinned. Keep their exact bytes;
changing them requires a separately scoped runtime release and compatibility work.
This README is repository navigation, outside the pinned kit manifest.
