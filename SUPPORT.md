# Getting help

Start with the [README](README.md), [reference docs](docs/reference/archive-format.md)
and `helseark --help`. Check the command's own help and current implementation
status; an agent prompt does not mean its workflow is implemented.

Ask usage questions or report reproducible bugs in
[GitHub issues](https://github.com/ricardocabral/helseark/issues). Include version,
OS, command, expected result and a synthetic example. Share only reviewed output;
error logs, filenames and screenshots can contain health data. Maintainers provide
best-effort help with no service-level guarantee. The project does not provide
medical advice, clinical interpretation, emergency support or record-recovery
services. Use the [security policy](SECURITY.md) for sensitive reports and the
[code of conduct](CODE_OF_CONDUCT.md) for behavior concerns.
