# What the evidence does and does not establish

The first lesson is one deterministic supplied candidate for one synthetic PDF,
with two Observations. It exercises toolkit contracts and an explicit synthetic
review decision. It runs zero models and measures neither extraction accuracy nor
human review effectiveness. The same-name isolation and installed recovery tests
add scope checks, not clinical certification.

Earlier actual agent observations are recorded separately in the repository's
[agent evaluation summary](../reference/evaluation-results.md).
Those observations concern the scenarios and sample sizes reported there; they
are not rerun by this documentation task. Original-source access requires explicit
host authorization. No telemetry is collected by normal archive operations.

A renderer receipt lists selected required paths, hashes and byte budgets. It does
not observe all filesystem reads, implicit host instructions or model activity.
An audit-hook trace measures the guarded Python process events it actually records;
ordered read events, unique bytes and repeated bytes must be reported separately.
Neither partial receipt logs nor a successful prompt establishes complete I/O telemetry.

Untested providers, general scan/OCR accuracy, terminology completeness, full FHIR
conformance, clinical accuracy and production readiness remain unclaimed. Remote
platform suites, independent final-union review and actual final-kit agent
scenarios are separate acceptance gates.
