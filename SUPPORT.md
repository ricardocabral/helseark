# Getting help

Start with the [README](README.md), [walkthrough](docs/tutorial.md),
[task guide](docs/how-to.md) or [schema reference](docs/schemas.md).
For the [experimental CLI](docs/optional-cli.md), check `helseark --help` and the command's help.
A prompt file does not prove that a command exists.

Ask usage questions or report bugs in [GitHub issues](https://github.com/ricardocabral/helseark/issues).
Include the page or template, expected result and an invented example.
For CLI problems, include the version, OS and command too.
Check logs, filenames and screenshots for private data before sharing.

Maintainers provide best-effort help without a service guarantee.
The project provides no medical advice, clinical interpretation, emergency support or record-recovery service.
Use the [security policy](SECURITY.md) for sensitive reports.
See the [code of conduct](CODE_OF_CONDUCT.md) for behavior concerns.
