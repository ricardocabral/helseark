# Experimental runtime references

For personal records organized with the [Helseark skill](../../skills/helseark/SKILL.md),
use the [schema reference](../schemas.md) and [task guide](../how-to.md).

The contracts in this directory describe the optional CLI's archive, validation,
review and packet machinery. Start with the [optional CLI overview](../optional-cli.md)
for current capability guidance. Retained protocol pages contain historical
implementation stages; their task numbers are not a roadmap or prerequisites for
the plain-file workflow.

Several files are hash-pinned in `definitions/lock.json` and copied into retained
agent-kit releases. Their exact bytes are preserved for runtime compatibility.
The overview records superseded capability statements without silently changing
those pinned contracts or users' retained archives.
