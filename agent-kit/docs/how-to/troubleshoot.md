# Recover from a blocked operation

For toolkit 0.1.2 / kit 0.1.17, keep originals and failed work until the cause is understood.
Start with `helseark --vault /absolute/vault doctor --json`. Record checkedChanges,
checkedResources, checkedAssets, issues and affected paths; zero counts do not
qualify a clinical archive.

DESTINATION_EXISTS means the target must be absent, even if it is an empty directory.
Choose a new packet, output, backup or restore destination and repeat the same
explicit scope. Do not remove another process's target to retry.

STALE_BASE means the selected history advanced. Stop the draft writer, prepare a
new proposal against the current head and inspect/review its exact bytes again.
REVIEW_MISMATCH means the reviewed inputs or host continuity are missing or changed;
re-prepare/review under approved-user control. Do not manufacture a digest from
editable files. An exact already accepted commit retry is safe and returns the
existing transaction.

PDF_INVALID, PDF_ENCRYPTED, PAGE_LIMIT and missing extraction dependency can return
a retainedSource receipt. Preserve its bytes, acquire compatible tools outside
normal offline operations or select another supported source, and use a fresh
packet. OCR_REQUIRED does not authorize cloud OCR or fabricated results.

UNKNOWN_PATH, hash failures and incomplete staging need preservation and inspection,
not hash repair or deletion. Restore a separately verified complete backup into a
new path, then compare counts, accepted bytes and scoped queries. See
[backup and restore](backup-and-restore.md). For missing/incompatible definitions or
kit, use an intact matching copy or compatible reader. Never repin accepted archives.
Fatal validation and unresolved identity cannot be acknowledged away. See
[CLI error codes](../reference/cli.md#errors-and-recovery).
